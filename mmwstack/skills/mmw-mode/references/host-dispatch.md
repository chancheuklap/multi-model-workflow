# Host subagent dispatch

Use this reference as the dispatching agent before starting, resuming, or closing any subagent on Factory Droid or Antigravity (AGY). Read the current host's section in `~/.agents/mmwstack-models.md` or the supplied model rule file, then apply that host's row below.

## Dispatch table

| Host | `mmw-agent` (playbook delegates) | `advisor` and `comment-sicko` | General-purpose delegates (readers, reviewers, runners, judges) | Notes |
| --- | --- | --- | --- | --- |
| **Codex / Claude Code / Cursor** | Spawn native `mmw-agent` with the step's model and settings. | Spawn native `advisor` or `comment-sicko` with its configured model and settings. | Spawn a fresh subagent with the role or seat model and settings. | Native role registration lives in `.codex/agents/`, `.claude/agents/`, or `.cursor/agents/`. |
| **Factory Droid** | Set `subagent_type` to `mmw-agent-<tier>`, replacing `<tier>` with the tier (`light`, `medium`, or `heavy`) from the step's entry in `## droid`. | Spawn native `advisor` or `comment-sicko`, bound to its tier in `.factory/droids/`. `comment-sicko` runs read-only. | Choose built-in `worker` when writes are needed, or `explorer` for read-only work including readers, reviewers, and cross-judges. Pass the role or seat tier as `Task.complexity`. Report a seat unavailable if neither built-in honors both tools and tier. | Sync `.factory/droids/` before launch after any tier or specialist binding changes. |
| **Antigravity (AGY)** | Run `~/.agents/scripts/agy-delegate --agent mmw-agent --model-role "<role>"` in local sessions, or pass `--model <id>`. | Run `~/.agents/scripts/agy-delegate --agent advisor --model-role advisor` or `--agent comment-sicko --model-role "judgment and prose"`. | Run `~/.agents/scripts/agy-delegate --agent none --model-role "<role>"` in local sessions, adding `--seat <n>` for a panel role or passing `--model <id>`. Using `--agent none` keeps blinded `eval` candidates and general-purpose delegates free of mmwstack role prompts. | Pass repeatable `--add-dir <worktree>` for target worktrees, and keep `--cwd` rooted in the Home Repo. Keep `--lifecycle auto`, or pass `--lifecycle ephemeral|gated|session` to override the role default. Resume a retained child only when required with `--resume <conversation_id>`, and close retained children with `~/.agents/scripts/agy-delegate close`. Sync `.agents/agents/` after role changes. |

## Antigravity (AGY) rules

- **Exact-model dispatch.** Use `~/.agents/scripts/agy-delegate` in local sessions so every delegate runs the exact model and reasoning level configured in `## agy` with its role instructions, `tools:` allowlist, isolated conversation, and repository hooks intact. AGY's built-in `invoke_subagent` and `.agents/agents/*.md` frontmatter accept only four coarse model tiers (`inherit`, `pro`, `flash`, `flash_lite`) and reject exact model IDs.
- **Isolated conversations over `swarm`.** Keep every mmwstack delegate in its own isolated conversation through `scripts/agy-delegate`. AGY's `swarm` shares a public message board across members, which breaks `arena` and `eval` blinding and conflicts with mmwstack review contracts.
- **Parallelism.** Launch independent `scripts/agy-delegate` calls as concurrent background shell tasks and wait for completion notifications instead of polling.
- **Fallback without `agy` CLI.** When `agy` is unavailable, such as in a cloud workspace without the CLI, fall back to `invoke_subagent` with the closest tier (`pro`, `flash`, `flash_lite`, or `inherit`) and record the fallback in the report.
- **Managed repository isolation.** Keep `scripts/agy-delegate` rooted in the Home Repo, and never pass a managed repository or its worktree to `--cwd`. Give each concurrent writer a sibling worktree of the target managed repository and pass that worktree's absolute path in the brief. Pass repeatable `--add-dir <worktree>` so AGY loads both Home Repo customizations and the target repository's `AGENTS.md` and project-local skills. From a Home Repo session, AGY `Workspace: "branch"` and `"share"` clone or share the Home Repo itself rather than the target repository.
- **AGY App and `agy` CLI runtime boundary.** Keep the default `--mode auto` with `scripts/agy-delegate`, and reserve `--mode herdr` for active Herdr Core terminals. `scripts/agy-delegate` always launches `agy` CLI under `~/.gemini/antigravity-cli/`, separate from AGY App under `~/.gemini/antigravity/` and AGY IDE under `~/.gemini/antigravity-ide/`. Pass only `agy` CLI or `scripts/agy-delegate` conversation IDs to `--resume`, never a non-CLI session ID from AGY App or AGY IDE. When reporting `agy` CLI delegates inside AGY App, cite the returned `transcript_path` instead of `conversation://<child-id>` links. `agy` CLI stores its authentication and settings separately from AGY App. If `scripts/agy-delegate` fails with an authentication error inside a logged-in AGY App session, report that `agy` CLI needs re-authentication instead of retrying as a network error. When searching local Antigravity conversation history, such as in `recall`, inspect both `~/.gemini/antigravity/` and `~/.gemini/antigravity-cli/` when present.

### Lifecycle, resume reuse, and close

- **Four lifecycle classes.** AGY child terminals use `ephemeral`, `gated`, or `session` under `scripts/agy-delegate`, while the `Main chat` and `Root coordinator` remain `top-level`.
  - **`ephemeral`.** An `ephemeral` child stays visible while running, closes its Herdr terminal and Herdr Core record after returning a settled result, and preserves its on-disk transcript. When the operator is viewing or peeking that terminal, closing defers until focus moves away unless the terminal is pinned.
  - **`gated`.** A `gated` child stays live after its turn for parent review or a bounded follow-up turn. It closes on an explicit `close` command, with a parent `Stop` hook safety net that sweeps settled, consumed, unpinned, unfocused idle children.
  - **`session`.** A `session` child survives across parent turns, `Hold` pauses, and hourly `Audit tick` runs until an explicit `close` at mission end, stuck replacement, `Pause safely`, or parent exit.
  - **Nested delegates.** Nested `ephemeral` and `gated` delegates spawned by a `session` owner close under their own lifecycle classes without waiting for their `session`-tier parent to close.
- **Default `--lifecycle auto` routing and overrides.** Pass `--lifecycle auto` by default, or pass `--lifecycle ephemeral|gated|session` to override the inferred class. Passing an invalid `--lifecycle` value or a removed retention flag (`--rm-terminal` or `--keep-terminal`) fails fast before launch. In headless mode, `--lifecycle` validates its value and exits on completion. When `--lifecycle` is `auto`, `scripts/agy-delegate` resolves the class in this exact order.
  1. Explicit non-`auto` `--lifecycle <ephemeral|gated|session>` always wins.
  2. Live-terminal `--resume <conversation_id>` keeps the reused terminal's existing lifecycle class (`agy_delegate_lifecycle`).
  3. Specialist `--agent` overrides apply next. `advisor` resolves to `gated`, and `comment-sicko` resolves to `ephemeral`.
  4. The `--model-role` map applies next. `coder` resolves to `session`. `advisor`, `feature, refactoring` (`feature` and `refactoring`), `bug-fix`, `perf-issue`, and `hillclimb` resolve to `gated`. `verifier`, `reader`, `code review`, `judgment and prose`, `arena runners`, and `arena cross-judge pool` resolve to `ephemeral`.
  5. Remaining calls fall back by `--agent`. `mmw-agent` with an explicit `--model`, no `--model-role`, or an unrecognized `--model-role` resolves to `gated`. `none` and all other agent names resolve to `ephemeral`.

  Pass `--lifecycle session` when a playbook needs cross-turn persistence for a non-`coder` role, such as a `Feature` multi-phase single owner. Pass `--lifecycle ephemeral` for a one-shot `mmw-agent` helper that needs no parent follow-up.
- **Live-terminal reuse on `--resume`.** In Herdr interactive mode, `--resume <conversation_id>` searches live direct children under the current parent matching `agy_conversation_id=<conversation_id>`. If a matching live terminal is `working` or `blocked`, `scripts/agy-delegate` fails fast with a non-zero exit that names the busy terminal address and status instead of opening a duplicate terminal. If that terminal is `done` or `idle` and meets any explicit model constraint, `scripts/agy-delegate` sends the follow-up prompt via `hc send` and returns only the new turn output. It keeps the terminal's existing lifecycle class unless a non-`auto` `--lifecycle` flag is passed. If no live child matches, it starts a fresh Herdr child terminal with `agy --conversation <id>`.
- **Explicit close commands.** Only the parent session (`HC_TERMINAL_ID`) closes its own direct children. Every close preserves the on-disk transcript and SQLite conversation history.
  - **Close one child.** Run `scripts/agy-delegate close <terminal-or-conversation-id>` to close an unpinned, unfocused `done` or `idle` direct child, including an explicitly named `session` child, via `hc kill` and `hc rm`. It fails non-zero when the target is `working`, `blocked` (`Needs you`), or pinned (`herdr.pinned`). It exits zero with `deferred` after setting focus deferral when the operator is viewing or peeking that terminal.
  - **Close all non-session children.** Run `scripts/agy-delegate close --all-mine` to close all eligible non-`session` direct children (`ephemeral`, `gated`, and focus-deferred) and reap `finished` child records. It skips `session`, `working`, `blocked`, and `herdr.pinned` children, and defers focused children.
  - **Force-close.** Pass `--force` only for `Pause safely` or stuck-agent replacement. `scripts/agy-delegate close <target> --force` closes the named child unconditionally. `scripts/agy-delegate close --all-mine --force` closes all direct children, including `session`, `working`, `blocked`, and focused terminals, while preserving `herdr.pinned` terminals unless named directly.
- **Failures and protection.** Automatic cleanup and non-forced close commands never close a terminal that is `working`, post-boot `blocked` (`Needs you`), or `herdr.pinned`. They defer closing when the operator is focused on or peeking that terminal. On a terminal non-fallback failure (non-zero exit or lost process, `error` status without retriable fallback, persistent startup `auth` block past the 15-second grace period, explicit `--timeout`, or exhausted `# fallback:` chain), `scripts/agy-delegate` returns the error detail, terminal screen output, and `transcript_path`, then kills and removes that failed child terminal immediately. Retriable `# fallback:` attempts clean up each failed attempt terminal before trying the next model candidate.
