# Host dispatch

Start a fresh subagent by default, and resume one only when the work needs state costly to move (uncommitted changes or a running process).
Begin every brief with `Read <path>/worker.md before anything else.`, and keep the delegate's session root in the parent's workspace (the Home Repo checkout in Home Repo workflows).
Read the active host's section in `~/.agents/mmwstack-models.md` (or the supplied model rule file), then read only your own host reference below and skip the others.
