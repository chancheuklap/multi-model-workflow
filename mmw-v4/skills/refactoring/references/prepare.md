# Prepare the structural change

**The structure changes; the behavior does not.** If cleanup reveals a missing feature or a real bug outside the agreed scope, return it to the caller as separate work. Within an agreed combined change, identify the behavior-preserving structural unit and its pins before the behavior-changing unit. A larger structure change returns to the same preparation for a spec.

1. **Learn the contract and choose the pin.** Reuse the known subsystem model; use **how** only for missing understanding needed to state the preserved behavior. Read every file the move touches per **principle-read-before-you-conclude**. Reuse the affected-feature result, or call **maintain-verification-skill**, **Find affected features**, when missing. Choose the characterization test, snapshot or equivalence harness that will pin current behavior. Reuse valid existing pins and their evidence. For a missing non-UI pin, prepare it with **test-audit** before any structural move, commit and push it on the effort branch. For a missing UI pin, return the current-behavior source, feature names and required states to the **to-tickets** caller, which prepares it before worker dispatch. Record the requirement rather than claiming an unwritten pin is green.

   If a selected pin uses an existing formal check, read its local method and correspondence record. When relevant code updates were skipped and no valid baseline proof exists, call **maintain-formal-verification-skill** before using that pin. Return its result; a discovered product defect keeps the caller's agreed scope.
   Done when the preserved contract and its proof are named, existing proof is linked, and every missing UI pin is explicitly assigned to ticket preparation before implementation.

2. **Name the structure the code is missing** per **principle-model-the-domain**. Done when the missing structure is named, or you have found the shape already clear.

3. **Name the target shape.** State what the module layout, types, and call graph should be if built today (**principle-model-the-domain**, **principle-redesign-from-first-principles**). Run the **prototype** skill on the target shape before the move; its `## Pick a branch` decides whether a sketch is drawn, committed on the supplied effort branch. Follow **principle-start-from-what-exists** before writing a helper. Done when the target shape is stated.

4. **Return the move's contract.** Return the contract, existing or prepared pins, missing UI-pin requirements, missing structure, target shape and any sketch. Read first names those baselines and this skill's implementation / verification entries. The first criterion is the pin, green before and after; a larger reshape also needs an equivalence check comparing old and new outputs or replaying the recorded baseline. The independent reviewer judges whether the structure reduces reader load, per **principle-minimize-reader-load**; record that review constraint separately from machine criteria.
   Done when the caller can write the move without inventing its behavior baseline or target structure.
