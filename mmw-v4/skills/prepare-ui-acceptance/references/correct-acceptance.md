# Correct frozen acceptance

Only the owner or original orchestrator corrects frozen acceptance after publication. Read the contract resolution, then read `references/new-design.md`, `references/repair.md` or `references/preserve-behavior.md` for its actual baseline. A changed UI design first returns to Design a UI and owner confirmation. Commit and push the corrected assets on the same effort branch and return the exact change and proof to the existing contract handler; this method does not resume workers or change the ticket's authority itself.
