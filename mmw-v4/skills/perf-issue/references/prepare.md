# Prepare the performance change

Use `references/diagnose.md` for missing workload and trace evidence. Retain existing results, and commit the benchmark command and baseline artifacts on the supplied effort branch before execution. A returned result resumes at the mechanism the measurements refuted.

1. **Plan the change** from the trace. A question of code shape goes to the **prototype** skill's `## Pick a branch` first. Done when the change and its target number are planned.

2. **Supply the performance plan.** Return the prepared material to the caller for **to-tickets**. **What to build** states the baseline number, the trace evidence, the planned change and the target, and asks for attempts sequenced per **principle-sequence-verifiable-units**. The first acceptance criterion is the benchmark command, vetted with the **benchmark-checklist** skill, printing a line only a run that meets the target prints; the second, the tests the change must keep green. Done when the caller has the baseline, trace, target, criterion commands and preserved-test requirements.

Read first points at the frozen workload, measurement command and this skill's verification entry. Return to the preparation caller.
