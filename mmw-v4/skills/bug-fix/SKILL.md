# bug-fix

Find a defect through a tight failing loop and runtime evidence, prepare its focused repair, or prove the original scenario after implementation. Every shipped line must follow evidence; a nearby green test is not proof that the reported bug is gone.

| Work in hand | Read |
| --- | --- |
| Answer why a defect occurs, within the caller's observation authority | [Diagnose](references/diagnose.md) |
| Prepare a justified fix on the supplied effort branch | [Prepare](references/prepare.md) |
| Implement the prepared repair under a ticket | [Implement](references/implement.md) |
| Verify the passed result on the original scenario | [Verify](references/verify.md) |
