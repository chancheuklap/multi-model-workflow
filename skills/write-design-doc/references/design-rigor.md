# design-rigor — 设计期查询清单

> `write-design-doc` 的"查得到就行"细则:架构判断本能、UI 设计硬规则、AI Slop 黑名单、UX 行为定律。主流程和模板在 `SKILL.md`;写到对应章节时翻这里对照,不用背。

## 架构判断本能（提方案时内化，别逐条罗列给用户）

- **默认无聊技术**：创新额度有限（约 3 个），其余一律用成熟方案；引入新基础设施前问"这张创新额度花得值吗"。
- **增量而非革命**：绞杀榕、灰度发布、重构，而不是大爆炸重写。
- **为凌晨 3 点的疲惫的人设计**，不是状态最好的高手。
- **可逆性优先**：单向门还是双向门？双向门（可逆）快做；单向门（不可逆 / 高影响）才慢下来，70% 信息够了就决策。
- **本质 vs 偶然复杂度**（Brooks）：加任何东西前问"这是在解真问题，还是解我们自己造出来的问题"。
- **看 blast radius**：最坏情况影响多少系统 / 多少人。
- **推倒重来的权利**：基础真的烂，明说"scrap it，换这个"，别把必要重写压成最小补丁。

## 交互状态与用户旅程

- **空状态是功能**：要有温度 + 主操作 + 上下文，不是"无结果"。
- **信息层级**：用户第一 / 第二 / 第三眼看到什么；只能放 3 样会放哪 3 样（constraint worship）。
- **用户旅程情绪弧**：步骤 / 用户做什么 / 用户感受 / 设计支撑了吗；三时域同时设计（5 秒直觉 / 5 分钟行为 / 5 年关系）。
- **响应式**：每视口刻意设计，不是"手机上堆起来"。
- **无障碍**：键盘导航 / ARIA landmark / 触控目标 ≥44px / 对比度 ≥4.5:1 / 正文 ≥16px。

## UX 行为定律（用户实际怎么用界面）

**可用性三定律**：
1. 别让我思考——每屏自明。
2. 点击次数不重要、思考成本才重要——3 次无脑点击胜过 1 次要想的点击。
3. 先删一半字再删一半。

**用户行为事实**：用户扫不读（为扫描设计：层级 / 分组 / 标题 / 高亮关键词）；用户 satisfice（选第一个够用的，把对的选项做成最显眼的）；用户瞎蒙着用（找到能用的就不放手）；用户不读说明。

**用约定 + trunk test**：logo 左上、导航顶 / 左、搜索 = 放大镜；除非确知有更好的别耍创意。盖住除导航外一切，仍能认出这是什么站、在哪页、有哪些大区。

**Goodwill reservoir**：用户带着善意进来，每个摩擦点都在消耗它。藏价格 / 强制格式 / 多余字段 / 强制引导都加速流失；说清他们想知道的、省步骤、易于纠错来补充。

**品味可调试**："这里感觉不对"必须能追到被违反的某条原则，不是主观。

## UI 设计硬规则

**先分类，再套规则**：marketing / landing（hero 驱动、品牌前置、转化导向）→ 落地页规则；app UI（工作区驱动、数据密集、任务导向：dashboard / admin / settings）→ 应用规则；hybrid（营销壳 + 应用区）→ 分区各套。

**通用硬规则（所有类型）**：定义 CSS 变量色系；不用默认字体栈（Inter / Roboto / Arial / system）；每个区块只干一件事；"删掉 30% 文案更好就继续删"；卡片要挣得自己的存在（不堆装饰性卡片网格）；标签可见（不能只用 placeholder 当标签）；已访问 / 未访问链接要可区分；标题贴它引导的区块，别浮在两段之间；正文 ≥16px、对比度 ≥4.5:1。

**落地页规则**：首屏读成一幅构图不是 dashboard；品牌优先层级（品牌 > 标题 > 正文 > CTA）；表达性字体；hero 满版、预算 = 品牌 + 一句标题 + 一句支撑 + 一个 CTA + 一张图；hero 不放卡片；2-3 个有意图的动效。

**应用规则**：平静的表层层级、强排版、少颜色；密但可读、少 chrome；卡片只在"卡片本身就是交互"时用；区块标题说清这是什么区 / 用户能干什么（"已选 KPI" / "计划状态"）。

## AI Slop 黑名单（命中 = 重做）

1. 紫 / 靛渐变背景或蓝到紫配色
2. **3 列「图标塞彩色圆圈 + 粗标题 + 两行描述」对称重复**（最像 AI 的布局）
3. 图标塞彩色圆圈当区块装饰
4. 全部居中（所有标题 / 描述 / 卡片 `text-align: center`）
5. 所有元素统一大圆角
6. 装饰性 blob / 浮动圆圈 / 波浪 SVG 分隔（区块显空是内容不够，不是缺装饰）
7. emoji 当设计元素
8. 卡片彩色左边框
9. 套话 hero 文案（"欢迎来到 X" / "解锁…的力量" / "你的一站式…"）
10. 千篇一律节奏（hero→3 特性→证言→定价→CTA，每段等高）
11. system-ui / -apple-system 当主显示 / 正文字体（"我放弃排版"的信号）
