# 原型 3：三个页签

「本机配置」分成三个页签，共用一个底栏和一个「保存」按钮：

- **会话角色**：runner 和「一个 agent 一行」，和现在的页面一样。
- **子代理**：开头一段说明子代理是什么（会话在自己的回合里临时派出的帮手，只在步骤点名时派，不是会话角色）。下面三行 `review-axis`、`reader`、`default`，每行一句中文用途；Claude 两格、Codex 两格（model、effort）。`inherit` 在页面上一律写「跟叫它的会话一样」。表下一句说明 Codex 的选项从哪来、读于何时、选「跟叫它的会话一样」时 effort 只剩哪几档（从接口取，不写死）。
- **型号目录**：原来的「本机的 host」一块（扫描时间、重新扫描）搬到这里。每个 host 一张卡：状态标签、「目录读于 …（N 小时前）」、读失败时一条斜线条写明失败种类（中文）和详情，以及仍在用哪一次读到的那份、现在可选的 model。下面一块「存的型号已不在目录里」：每个出问题的格子一行，写明是哪一格、存的名字、现在可选的名字，旁边一个「跳到这一格」按钮，点了切到那个页签、滚到那一格并把焦点放上去。

出问题的格子自己也写明存的名字和现在可选的名字（斜线条，和现在页面的「start 会拒绝」一样），所以不进型号目录页签也看得到。

页签名后面带小标记：会话角色、子代理两页显示「N 处不对」（斜线）或「改了 N 处」；型号目录显示「读取失败」「N 格旧型号」。底栏的改动计数和问题计数把三页合起来算，问题提示写明在哪个页签。

保存仍是一次 `PUT /api/settings`，多带一个 `subagents`。422 时，指到子代理格子的错误会自动切到子代理页签并给那一格画斜线；指不到任何格子的错误（如 `version`）在页签上方用斜线条列出。409 和「重新读取」、扫描中不能保存、Esc 关闭、点遮罩关闭（没改动时）都和现在一样。

## 在这个角度里考虑过、没选的

- **一页滚到底，三段之间用分隔线，顶上放段落跳转**：三件事都在眼前，但页面会很长（会话角色 7 行 + 子代理 3 行 + 两张 host 卡 + 旧型号列表），「各自成段」只是视觉上的；跳转也只是滚动。选页签，是因为它让每一段真正只讲一件事，切换时底栏不动。代价是一次看不到全部，所以给每个页签加了改动/问题标记，底栏也写明问题在哪个页签。
- **型号目录不单独成页，而是把读取时间和失败原因挂在每个 host 下拉框旁边**：这正是本角度要避开的「分散」，留给别的候选。
- **把「本机的 host」那一块留在页签上方，三页都看得到**：它和型号目录是同一件事（扫描就是读目录），留在上方会让目录信息分在两处；搬进型号目录页签后，会话角色页签的开头直接是 runner。
- **子代理按 host 分两张小表（Claude 一张、Codex 一张）**：每行的用途要写两遍，三行又很短，合成一张五列的表更省地方，列头上用「Claude」「Codex」分组。

## #1025 §11 没定、这里替它定了的

- **子代理的中文用途**：用 `roles.json` `subagents` 段的英文用途和 #1025 §1 的表译出来，暂放在本模块的 `SUBAGENT_WHAT`。§11 要求它和会话角色的说明放在一起，进产品时应搬到 `local-config.mjs` 的 `LocalConfig.ROLE_WHAT` 旁边（本目录之外，原型不改）。
- **列头用 model / effort**，不用「型号 / 强度」：和同一页「一个 agent 一行」的列头一致。
- **Codex 换 model 后，原来的 effort 新 model 不支持时**：改成「跟叫它的会话一样」（对任何 model 都合法），并计入改动，不留一个保存会被拒绝的空格。
- **存的型号已不在目录里算不算「不对」**：算。页面照接口给的 `stale` 列表判定，不自己另写规则；这一格不改，`models.py` 保存时就会拒绝（子代理 Codex 一格会被 `_validate_subagents` 拒），所以保存按钮先灰掉，写明原因。选了新名字，这一条就消失。
- **读失败但还有旧目录**：host 的状态标签照接口给的显示；失败原因写在标签下面的斜线条里，并说明仍在用哪次读到的那份。
- **读取时间的写法**：今天以内写 `HH:MM（N 小时前）`，更早的加上月日。

## 原型里的临时做法

- 「重新读取」要拿到 `fake.mjs` 补的字段，所以经由 `mount.mjs` 的 `fromPayload`；产品里直接用本模块自己的。
- 「重新扫描」的回答没有 `read_at` 时，用这次扫描的时间代替；接口补上 `read_at` 后去掉这一条。
