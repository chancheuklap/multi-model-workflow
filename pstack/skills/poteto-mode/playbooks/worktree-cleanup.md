### Worktree and simulator cleanup

1. Snapshot and audit. Record `df -h /`, then run `scripts/worktree-audit.sh [-b <pr-base-ref>] [--transcripts <workspace-transcript-dir>] [repo-path]` ([principle-build-the-lever](../../principle-build-the-lever/SKILL.md)). Without `-b` it checks `MERGED` against `origin/HEAD`, so pass `-b origin/<branch>` when PRs target another branch. It reads paths from `git worktree list`, never hand-typed, so it also finds worktrees outside the repository ([principle-encode-lessons-in-structure](../../principle-encode-lessons-in-structure/SKILL.md)). It classifies each worktree by size, age, merge state, uncommitted work, PR state, and the modification time of the newest transcript that mentions its path, then suggests a bucket. Pass this workspace's transcript directory when available. Without it the script reports `unknown` for chat activity. The transcript scan is slow, so background it.
2. The bucket is advice, not permission. The pinned and active chats are the real artifact ([principle-prove-it-works](../../principle-prove-it-works/SKILL.md)). Get that set from the workspace session list or the user and cross-check every candidate. The lever has marked `safe` a worktree the user had pinned, so the pinned set wins.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan subagents out to read the transcripts and report which worktrees the chat touches and whether it is pinned or ongoing, using the chat records and the pinned set from step 2 ([principle-guard-the-context-window](../../principle-guard-the-context-window/SKILL.md), transcripts are bulk). A pinned chat spawns arena and repro trees into sibling worktrees via background subagents, and those are in use even when their names never appear in the chat list. Pick each subagent's reasoning level and fast or standard speed for the job, per the Subagents section.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. Show the diff and get a decision first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. Per Autonomy, clean and merged and not-in-use proceeds. `wip` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove --force <path>`. If the dir survives on ignored build artifacts, `rm -rf` it, then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, measured application caches, package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in-use by which chat, or uncommitted work).
