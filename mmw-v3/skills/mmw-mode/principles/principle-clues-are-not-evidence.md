# Clues are not evidence

A Memory record, an advisor's answer, another agent's report and a review finding are clues. Before you act on one, verify it against the current repository, the tracker and the result of a run.

**Pattern:**
- **Let the clue say what to verify.** Use Memory, Thread, Working Memory, agent reports, and issue status to discover what to verify; use primary tracker, git, repository, and check evidence to establish what happened or landed.
- **Follow every claim back to the source that owns it.**

Distinct from Prove It Works, which checks your own finished work against the real thing; this checks what you were told before you act on it.
