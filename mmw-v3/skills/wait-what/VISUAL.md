# Re-pitch it visually

The `visual` branch of [`wait-what`](SKILL.md). Same job as the prose re-pitch (make the thing that did not land land), with one HTML page carrying the explanation. Every label on the page uses the ubiquitous language of `CONTEXT.md`, because the user carries those names into the next message.

Explain what was already said. The material is the message the user just stopped you on, not a fresh investigation.

## Draw the page

Read the `diagram-design` skill's `SKILL.md` and follow it: it sets the page's look, draws every picture on it, says what the words beside the pictures do, and where the page goes.
