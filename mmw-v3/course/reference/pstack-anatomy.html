pstack 组件解剖

八种组件各在哪、长什么样、谁在什么时候读它。第 1 课的压缩版，用来查。

八种组件

组件在哪、几个文件形状什么时候被读怎么被用到
mode skillskills/poteto-mode/SKILL.md
1 个，2,971 词		frontmatter；7 节：Non-negotiables、Principles、Autonomy、Subagents、Writing the reply、Comments、Playbooks任务开头读全文，之后每轮都在你输入 /poteto-mode，或把它当 Custom Mode；子代理 poteto-agent 开工前读它
playbookpoteto-mode/playbooks/*.md
23 份，127–2,636 词		无 frontmatter；### 标题、**You own …**、编号步骤、**Reply:**任务匹配上它时，只读这一份mode 的 ## Playbooks 路由行，或另一份 playbook 的一步（例 Run Opening a PR）
principleskills/principle-*/SKILL.md
24 个，126–773 词		description 以 Apply 开头写条件；# 标题、规则、**Why:**、**Pattern:** 等开头只读 mode 索引里的一行；条件出现、要应用时读全文mode 的 ## Principles 索引；playbook 或技能的某一步点名
skillskills/<名>/SKILL.md
25 个，40–1,636 词		frontmatter；# 标题、用途、选模型一段、## Start、阶段或步骤、交回什么被点名时你输入 /名字；mode 的触发行或 playbook 的步骤点名。49/50 个技能设了 disable-model-invocation: true
references/挂在某个技能下
9 个技能，共 31 份		给子代理的提示词模板（带占位符），或查表用的判断表、评分标准点名它的那一步执行时技能或 playbook 的一步写 references/<文件>
scripts/poteto-mode/scripts/ 4 组；show-me-your-work/scripts/log.sh普通程序，开头注释写做什么、不做什么；大的带测试点名它的那一步执行时步骤给出命令，agent 运行
subagentagents/*.md
2 份		frontmatter：name、description、is_background；正文是子代理的提示词开子代理时Task 调用的 subagent_type；mode 的 ## Subagents 规定用 poteto-agent
rule~/.cursor/rules/pstack-models.mdc
1 份，插件外		alwaysApply: true；# budget:；一行一个角色和模型每个会话都带着；开子代理时查角色行由 setup-pstack 写出；各技能的选模型一段读它，缺行用默认值

不给 agent 读的：.cursor-plugin/plugin.json（插件清单）、README.md、docs/guide/（给人读的 10 章指南）、automations/benny/（休眠的自动化包，复制到目标仓库后才用，里面的 SKILL.md 不登记为技能）。
