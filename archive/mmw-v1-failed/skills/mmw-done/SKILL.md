## 怎么做

1. 逐条过收尾清单：文档都提交了、分支没有未提交改动、相关测试跑一遍是绿的、本次新写的 TODO 与 FIXME 扫一遍、审都过了。有一条不过，当场修、开成独立后续、确认不是问题，三选一。
2. 摊开 `.mmw/sidelines.md` 给用户挑哪些开成远端 issue，一次性开完。往远端写要用户点头。
3. 合并回主分支：`git -C <主仓库> merge --no-ff <任务名>`。**禁止压扁提交**。
4. 清工作树：`git worktree remove .mmw/worktrees/<任务名>`。状态文件与旁路清单随它一起消失。
5. 告诉用户合到哪、开了哪几个 issue、工作树清了。
