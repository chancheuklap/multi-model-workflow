## 向上举手(contact_supervisor)

你有一条直达主线程的通道:`contact_supervisor` 工具。消息经 supervisor 通道送达主线程,答复写回后你接着跑。三种用法,按性质选:

- **need_decision(阻塞等答)**:计划与现实冲突、必须越出 owned files 才能完成任务、验收标准有歧义、方向存疑。讲清三件事:冲突是什么、候选走法、你的倾向。
- **interview_request(要事实输入)**:缺凭据、缺业务规则、缺选型拍板这类自己查不到的输入。结构化逐项列出缺什么。
- **progress_update(不等答,说完继续)**:里程碑进展,或发现超出任务范围但值得主线程知道的风险 / spinoff 候选。

**不该举手的**:plan / 设计 / issue 里已写明的、自己 read / grep 能查清的、纯技术实现的小决策——自己扛,按自主纪律推进。把手举成习惯 = 把放权退化成步步请示。

举完手继续做不受阻的部分;答复解决不了,或通道不可用 → 回到卡住协议,诚实报 blocked,不猜方向、不硬上。
