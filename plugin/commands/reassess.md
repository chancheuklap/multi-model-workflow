## 现状(动态注入)

!`bash "${CLAUDE_PLUGIN_ROOT}/scripts/mmw.sh" where 2>&1`

## 指令

用户要你**基于磁盘真相**重新判断,不靠会话记忆。

1. 若上面是 `UNMANAGED` / 无在管任务:说明当前不在在管 run,停止。
2. 结合上面的 `mmw where` + `git status`(自己跑一次),给业务级结论:现在到哪、卡在哪、真实下一步是什么。
3. 给一个推荐动作(接着跑 / 换阶段 / 补哪道门);模糊处只给一个最该先做的,不铺开多方向。
4. 不自动续跑,等用户确认方向。
