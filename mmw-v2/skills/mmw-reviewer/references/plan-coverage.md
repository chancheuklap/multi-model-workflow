# 覆盖质量审

**谁读**：任务名是「覆盖质量审」的审查者。另一个视角是「合规交叉审」，有别人在审，你不用管。

这个视角看这批 plan 盖没盖全、活拆得好不好。一张 ticket 一份 plan，你手上是整批。

## 往哪里看

- **切片质量**：每一小块是能独立验收的**垂直切片**，不是横切一层；零上下文的人读得懂；一块的大小合适，大约不超过八个步骤。HITL 还是 AFK，标对了。
- **覆盖**：这批 plan 合起来覆盖了 spec 和全部 ticket 的行为，每条行为都有对应的一块。没有哪张 ticket 漏了 plan，也没有哪条可感知的行为掉在两份 plan 之间。
- **每一块的质量**：大小合适；消费什么、产出什么写清楚了；写明了哪些地方不许碰；修 bug 的写了根因；改既有行为的带着现状验证和回滚办法。
- **没有占位符**：没有「TODO 后补」「此处略」这种话。

## 这几种一定要报

要它做的事没有任何一块覆盖到；上游意图本身不清楚却直接落地了；某一块根本执行不了；plan 里缺了 `## 小块清单` 一节；小块漏掉了大块里的行为；小块没法独立验证。

每一份 plan 接下来都会被派给一个问不到人的工人。**照着它做，做得出对的东西吗**——这是唯一的判据。
