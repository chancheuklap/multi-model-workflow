把「去把仓库现状查清楚」这件事派出去，你继续做别的。

**你不查。** 一个角度交给一个 subagent。你的职责是定角度、组装提示词、派发、过滤、验证、综合。

**只查这个仓库里读得到的东西。** 第三方文档、外部接口、别人的实现，走 `/mmw-research`，那是另一件事，出处的形状和检索的手段都不一样。

**窄到一个点的不要派。** 一个函数、一个已知文件、一条查得出答案的命令，你自己 Read 或者 Grep 完就走，派发的往返比查本身还慢。

## 1. 定角度

一个 subagent 一个角度。**按角度分，不按范围分**：每个人都看同一片地方，各自带一个不同的角度。范围一切，跨边界的那类发现就没人看得见了——一个概念散在三个模块里、一处耦合从 seam 漏进另一个子系统，恰恰是最值钱的那类。反过来，一个 subagent 同时背几个角度会趋同，找到第一个之后剩下的注意力都还留在那附近。

一个角度写两样：

- **角度** —— 这一题从哪个方向看。
- **要回答什么** —— 一句话，能判真假。「订单受理这个模块的公开边界有哪些」答得上，「订单模块写得好不好」答不上。

角度定几个按这次真实需要，不凑数也不设上限。常用的几个：这块功能现在怎么实现、seam 在哪、数据从哪来到哪去、改动会波及谁、测试现在覆盖到哪。

收不成这个形状就停下来说清楚——是这件事本身要人拍板，还是它得先拆开。

## 2. 把角度清单亮给用户

按这个形状亮一次，然后**直接往下派，不等他回应**：

```
| # | 角度 | 要回答什么 |
```

方向定错了他会当场打断。停下来等，等来的多半是「嗯」，白花一轮往返。

## 3. 组装提示词

从文件里取，不凭记忆：

1. 本文件旁边的 `investigator-brief.md`，全文。
2. 这一题的角度和要回答什么。
3. **目标仓库根的绝对路径**，并写明只许在这个路径下取证。不钉死它，subagent 会在自己当前所在的目录取证，交回一整份跟这次无关的结论——你在任务 worktree 里工作时尤其容易踩到，主仓库和各棵 worktree 长得一模一样。
4. 这个仓库的领域词（`CONTEXT.md`，多 context 的仓库按 `CONTEXT-MAP.md` 找到对应那几份），让它用项目的词命名它找到的东西。
5. 已经知道的背景：查过哪里、排除过什么。让它从你停下的地方接着查，不要从头再来一遍。

写到 `.dispatch/<slug>-investigate-<角度短名>.prompt.md`（先 `mkdir -p .dispatch`）。

## 4. 派发

按 `/mmw-dispatching-agents` 派，**只读沙箱**——它不改代码也不写文件。模型档从 `docs/agents/models.md` 取。

角度之间互不依赖，一条消息里全部并行发出去。

## 5. 过滤，验证，综合

收回来之后按这个顺序做三件事。

**先机械过滤。** 引不出 `文件:行号` 的断言直接丢掉，这一步不做判断、只看有没有出处。**丢掉的要在你的报告里列出来**，写明丢了几条、分别是什么——静默吞掉会让人以为那部分查过了。

**再逐条验证。** 按 `/mmw-verifying-agent-output` 验证留下来的：打开那个 `文件:行号`，看原文对不对得上。条目多的时候取证那一半可以派出去，判定仍然归你。

**报告说「没有找到」的那几条格外要自己再查一次。** 它可能只是没搜对名字。「这个行为还没实现」「这里没有测试」这类结论会直接改变下一步做什么，判错的代价比一条错引用大得多。

**最后你自己综合。** 跨角度去重、把相关的事实串起来，每条保留 `文件:行号`。综合不要派——它是判定的开始，而判定是你的活。

**验证过的事实才往下走。** 落到哪里由调用方决定：写进 spec 的现状一节、写进 ticket、或者只是你接着往下判断的依据。

## 下一步

| 情况 | 下一步 |
| --- | --- |
| 验证完了 | **移交**：回到把你叫起来的那个技能，带上验证过的事实，不是报告原文 |
| 验证完了，是用户直接叫你来查的 | **停**：报查清了什么、哪些没查清、机械过滤丢掉了哪几条 |
| 出处点开对不上，或者根本没给出处 | **自己继续**：确认 `investigator-brief.md` 全文在提示词里、仓库根也钉死了，重派一次 |
| subagent 报了「没有找到」，你自己再查一次找到了 | **自己继续**：以你查到的为准，并且把这个角度整份报告降级重验——它漏了一处，多半不止漏一处 |
| subagent 在报告里提了方案、选了路线 | **自己继续**：那部分不采信，只取它的事实和出处。方案归调用方定，不归调查员 |
| subagent 交回「卡住」，理由是这块代码它看不懂 | **停**：报是哪一块、它卡在哪里，让用户定是换个角度问还是他自己来讲一遍 |
| 第 1 步角度收不成能答得上的形状 | **停**：说清是要人拍板，还是这个角度得先拆开 |
