原型是**为了回答一个问题而写的能跑的东西**。问题决定它长什么形状。

**它的产物是资产，不是一次性代码。** 验证过的逻辑模块会被搬进正式代码，用户选中的界面变体是实现时的视觉契约。所以它落在仓库里、随设计一起提交、原地迭代——不另起临时分支重做一版。

## 一轮只回答一个问题

开写之前先把这一轮要回答的那个问题写下来，一句话。判据是**用户走查完能给出一个明确答案**：逻辑那侧的答案形如「对」或者「不对，因为退款窗口关闭之后这条路走不通」；界面那侧的答案形如「选 B，页头换成 C 的」。「这个设计好不好」得不到明确答案，收不成这个形状先回 `/mmw-grilling` 谈清楚。

要问的有好几个时，排出当前最承重的那个先做，其余等这一轮走查完再开新一轮。

问题产自讨论，不凭空造。

## 选一条 branch

| 这一轮要回答什么 | 走哪条 |
| --- | --- |
| 这套逻辑、状态转移或者数据形状对不对 | [LOGIC.md](LOGIC.md)。做一个小的 TUI，让用户手动把状态模型推过纸上想不清楚的那些情形 |
| 它该长什么样 | [UI.md](UI.md)。在同一个路由上给出几个结构截然不同的界面变体，用 URL 查询参数和一个浮动底栏切换 |

两条 branch 产出的东西完全不同，选错等于整轮白做。问题确实两可、用户又不在场时，按周边代码判——后端模块走逻辑，页面或组件走界面——并在原型开头写明这个假设。

## 两条 branch 都适用的规矩

1. **一条命令跑起来。** 用项目已有的任务入口（`pnpm <名字>`、`python <路径>`、`bun <路径>`），用户不用想就能启动。项目没有任务入口时，把命令写在 `README.md` 开头。
2. **默认不落库。** 状态放内存。持久化是原型要*检验*的东西，不该是它的依赖。问题本身就是关于数据库的，就连一个临时库，或者一个名字里带 `PROTOTYPE — wipe me` 的本地文件。
3. **不打磨。** 不写测试，错误处理只做到能跑起来为止，不做抽象。
4. **把状态摊开给人看。** 每次操作之后（逻辑原型）或者每次切换变体之后（界面原型），把相关状态整个打出来或者渲染出来，让用户看得见变了什么。
5. **覆盖真实存在的边界，不只演顺利路径。** 具体覆盖哪些边界见各自的 branch。

## 落在哪

```
docs/prototypes/<slug>/
├── README.md              逐轮记录
├── logic/                 逻辑原型源码
├── mockup/                界面变体
└── runs/<三位轮次>/        这一轮的截图、运行输出等证据
```

`<slug>` 取当前 worktree 的 slug（见 `../../conventions/worktrees.md`）。第 2 轮的证据放 `runs/002/`。

还在主仓库里、没有任务 worktree 的，先按 `../../conventions/worktrees.md` 建一棵再动手。原型要提交，主仓库不接受直接写。

**原地迭代，不复制版本目录。** 下一轮继续改同一份源码，保留已经确认过的状态、交互和文案，历史由 git 保存。

**这个目录不随 spec 一起删。** spec 落地之后要转 Wiki，本地的 `docs/specs/<slug>/` 会被删掉（见 `../../conventions/issue-tracker.md`）；原型产物留着，它们是实现时的素材。

`README.md` 每轮追加一节，记五件事：这一轮要回答的问题、用户反馈或者本轮假设、基于上一轮实际改了什么、怎么验的和结果是什么、这一轮的结论。结论只有三个词：

| 结论 | 什么意思 |
| --- | --- |
| `continue` | 还没定下来，登记下一轮要回答的问题接着做 |
| `accepted` | 用户明确接受了，写清楚选中的是哪几份产物 |
| `superseded` | 验证证明这个方向本身不成立 |

每轮走查完立刻提交：这一轮的源码、`README.md`、证据文件放同一个提交，不夹带无关文件。

## 走查是人闸

原型做出来是给用户走查的。把当前产物和运行结果摆给他，记下他的原话或者你的明确假设。**不替用户宣布定稿**，走查没过的时候也不并行往下写正式代码。

派一个子代理自问自答，它给的结论不作数。

## 下一步

| 情况 | 下一步 |
| --- | --- |
| 这一轮要回答的问题已经写下来，是逻辑或者状态的事 | **自己继续**：读 [LOGIC.md](LOGIC.md) |
| 这一轮要回答的问题已经写下来，是界面长什么样的事 | **自己继续**：读 [UI.md](UI.md) |
| 用户走查过了，明确接受了某份产物 | **自己继续**：读 [capture.md](capture.md)，把结论回灌 |
| 用户走查之后还要改 | **自己继续**：回本文件开头，登记下一轮要回答的问题 |
| 验证证明这个方向本身不成立，而且是别的技能把你叫起来的 | **移交**：回到那个技能，带上击穿这个方向的那个事实。不在这个方向上另造一版 |
| 验证证明这个方向本身不成立，而且没有别的技能在等你 | **移交**：`/mmw-grilling`，重新谈方向 |
| 要问的问题收不成能明确回答的形状 | **移交**：`/mmw-grilling`，把它谈清楚再回来 |
