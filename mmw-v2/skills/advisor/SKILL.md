# Advisor

Two doors, and this run is at one of them.

| You are | Read |
| --- | --- |
| An agent that has hit a decision and is weighing a second opinion | [Consulting the advisor](references/consulting.md) — when it is worth a session, how to start one, what the question carries |
| The session started as the advisor: your prompt is a question packet and nothing else | [Advising](references/advising.md) — how to answer, and what the packet does not get to decide |

The two sides are asymmetric on purpose. The caller owns the decision and the evidence; the advisor owns what it reads and what it concludes.
