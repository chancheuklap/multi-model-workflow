把「去查清楚」这件事派出去，你继续做别的。

**你不查。** 一个题目交给一个 subagent。你的职责是定题目、组装提示词、派发、验证、存盘。

## 两个方向

| 方向 | 查什么 | 出处长什么样 |
| --- | --- | --- |
| 内部 | 这个仓库现在怎么实现：模块边界、seam、数据流、调用链、根因 | `文件:行号` |
| 外部 | 仓库之外的事实：某个库的行为、某个接口的合同、某份规范的语义 | 完整链接，或者命令原文加它打印的关键几行 |

两个方向的题目可以在同一次里一起派，一个题目一个 subagent。只要一个方向的就只派那个方向。

**窄到一个点的不要派。** 一个函数、一个已知文件、一条查得出答案的命令，你自己 Read 或者 Grep 完就走，派发的往返比查本身还慢。

## 1. 定题目

一个 subagent 一个题目。题目要收得能答得上：「那个接口支不支持按游标分页」答得上，「那个接口好不好用」答不上。

按**角度**分题目，不按**范围**分。每个调查员都看同一片地方，各自带一个不同的角度。范围一切，跨边界的那类发现就没人看得见了——而那恰恰是最值钱的。

一个题目写两样：

- **角度** —— 这一题从哪个方向看。
- **要回答什么** —— 一句话，能判真假。

题目定几个按这次真实需要，不凑数也不设上限。

收不成这个形状就停下来说清楚——是这件事本身要人拍板，还是它得先拆成几个题目。

## 2. 把题目清单亮给用户

按这个形状亮一次，然后**直接往下派，不等他回应**：

```
调查方向：内部 / 外部 / 两者
| # | 角度 | 要回答什么 |
```

方向定错了他会当场打断。停下来等，等来的多半是「嗯」，白花一轮往返。

## 3. 组装提示词

从文件里取，不凭记忆：

1. 本文件旁边的 `researcher-brief.md`，全文。
2. 这一题的角度和要回答什么。
3. 内部方向的，**给出目标仓库根的绝对路径**，并写明只许在这个路径下取证。不钉死它，subagent 会在自己当前所在的目录取证，交回一整份跟这次无关的结论——你在任务 worktree 里工作时尤其容易踩到。
4. 已经知道的背景：查过哪里、排除过什么。让它从你停下的地方接着查，不要从头再来一遍。

写到 `.dispatch/<slug>-research-<角度短名>.prompt.md`（先 `mkdir -p .dispatch`）。

## 4. 派发

按 `/mmw-dispatching-agents` 派，**只读沙箱**——它不写文件。模型档从 `docs/agents/models.md` 取。

题目之间互不依赖，一条消息里全部并行发出去。

## 5. 过滤，验证，综合

收回来之后按这个顺序做三件事。

**先机械过滤。** 引不出出处的断言直接丢掉，这一步不做判断、只看有没有出处。**丢掉的要在你的报告里列出来**，写明丢了几条、分别是什么——静默吞掉会让人以为那部分查过了。

**再逐条验证。** 按 `/mmw-verifying-agent-output` 验证留下来的：内部的点开那个 `文件:行号` 看原文对不对得上，外部的点开链接看它是不是一手来源。条目多的时候取证那一半可以派出去，判定仍然归你，判法在 `/mmw-verifying-agent-output`。

**最后你自己综合。** 跨题目去重、把相关的事实串起来，每条保留出处。综合不要派——它是判定的开始，而判定是你的活。

**验证过的事实才往下走。** 落到哪里看这次是谁要它：

| 谁要的 | 落到哪 |
| --- | --- |
| `/mmw-wayfinder` 的一张调查类 ticket | 那张 ticket 的评论，然后关掉它 |
| 别的技能 | 交回给把你叫起来的那个技能，由它决定 |
| 用户直接叫你来查 | 按 `docs/agents/domain.md` 的落点写一份文件，或者他指定的位置 |

交回来的出处是二手转述、或者点开对不上，那是 brief 没生效——把 `researcher-brief.md` 补进提示词重派，不要自己替它找出处。

## 下一步

| 情况 | 下一步 |
| --- | --- |
| 验证完了，是别的技能把你叫起来的 | **移交**：回到把你叫起来的那个技能，带上验证过的事实，不是报告原文 |
| 验证完了，是用户直接叫你来查的 | **停**：报查清了什么、报告落在哪、哪些没查清、机械过滤丢掉了哪几条 |
| 出处是二手转述，或者点开对不上 | **自己继续**：确认 `researcher-brief.md` 全文在提示词里，重派一次 |
| subagent 交回「卡住」，理由是找遍了没有一手来源 | **停**：报这个题目查不到一手来源、它查过哪些地方，让用户定是换个问法还是接受不确定 |
| subagent 在报告里提了方案、选了路线 | **自己继续**：那部分不采信，只取它的事实和出处。方案归调用方定，不归调查员 |
| 第 1 步题目收不成能答得上的形状 | **停**：说清是要人拍板，还是这个题目得先拆开 |
