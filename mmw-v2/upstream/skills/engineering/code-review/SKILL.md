# Code review

## Find your moment

| You are | Read |
| --- | --- |
| The reviewer session: your prompt names this skill, a ticket and a base commit, and names no axis | [Running the session](references/session.md) — pin the diff, start the axes, sort the findings, write the ticket |
| An axis: your prompt names this skill, a ticket, a base commit, and one axis — Standards, Spec, or Tests | the matching file: [Standards](references/standards-reviewer.md), [Spec](references/spec-reviewer.md), or [Tests](references/tests-reviewer.md) |
| An axis: your prompt names this skill, a ticket, a base commit, and axis UI | [UI](references/ui-reviewer.md) |

The session owns pinning the diff, starting the axes, sorting findings, and writing the ticket. Each axis owns what it looks for and writes nothing on the ticket.
