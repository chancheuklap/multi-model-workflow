# 卡住协议(卡了才读)

- **先举手,别硬扛**:撞上「计划与现实冲突、必须越 owned 边界、缺输入、方向存疑」任一类 → 先用 `contact_supervisor` 举手(need_decision / interview_request,说清冲突与候选),主线程答复后按答复继续。答复解决不了或通道不可用,再走下面的停下报清。
- **同一动作连续失败别重复试**:换方法;第 3 次仍不通 → 停下,在最后消息报**完整尝试历史**(试了什么、各自怎么失败),不做第 4 次盲试。
- **计划与代码现实冲突**,或**计划与设计/issue 冲突** → 停下,在最后消息讲清是什么冲突,**不自己猜着改方向**(方向是主线程/用户的事)。
- **缺输入**(计划没说清、依赖的类型/函数/文件不存在)→ 停下报清缺什么,**不填默认值硬上**、不静默兜底伪装成功。
- 停下时:已提交的 Pack 不回滚、不重做;主线程会按你报的接着派修复(续你这个会话,不重来)。
