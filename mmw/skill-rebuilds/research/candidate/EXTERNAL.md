# 外部 research

只在当前角度需要查明当前工作目录之外的事实时读取本文件。

## 选择一手来源

一手来源由事实的所有者决定：

| 事实 | 一手来源 |
| --- | --- |
| 库或框架的行为 | 官方文档和官方源码 |
| API 合同 | API 提供方的正式文档、规范或第一方 API |
| 语言语义或行业协议 | 正式规范 |
| 版本声明和发布行为 | 官方发布记录、官方源码或第一方接口 |

网页搜索和文档检索工具只用于找到一手来源。博客、问答、教程和搜索结果页面不能作为最终出处。

一条只读命令能够直接显示版本、实际返回或命令行为时，可以运行该命令，并保留命令原文和支持断言的关键输出。

上一条的边界是**只读**。这个角度要回答问题必须动到下面任意一条时，停下来，向主 agent 说清楚要跑的是什么、为什么只读不够，由主 agent 决定怎么办：要用真实凭证、要连生产环境、会产生费用、会写入外部系统的数据、要施加负载或者要多轮测量。这个角度必须靠一个能跑起来给用户点的东西才能回答时，同样停下来交回。这两种你都不要自己动手。

每项断言都要引用具体的一手来源页面、章节、源码位置或命令输出。文档与实际输出不一致时，两项都要保留并明确区分。记录资料的访问日期和与结论有关的版本。

## 交回报告

按以下顺序交回：

1. task 点名的具体问题和范围。
2. 已查明的事实及其一手出处。
3. 文档、源码、规范或实际输出之间的冲突。
4. 未查清项、原因和已经查过的来源。
5. 访问日期和相关版本。

完成判据：task 点名的问题已经得到一手来源支持的答案，或者已经列出未查清原因和查过的来源。
