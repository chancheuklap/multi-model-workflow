# skill-rebuilds

MMW 的重建区。这里保存上游翻译基线、翻译审计，以及每一轮改了什么的台账。这些文件**不会**被 `mmw skills materialize` 物化。

2026-08-16：各技能目录下的 `candidate/` 已覆盖进 `mmw/skills-src/`（角色 body 进 `mmw/agent-src/bodies/`），并随 0.30.0 物化进各宿主产物。此后改技能改现役源，不再改 candidate 再整体替换。

## 目录里有什么

| 位置 | 是什么 | 会不会进发布面 |
| --- | --- | --- |
| `<上游技能名>/candidate/` | 该技能这一轮已经发布的英文候选（台账副本） | 已经进过。不要把它当成第二份现役源 |
| `<上游技能名>/` 其余文件 | 上游翻译基线、翻译审计、这一轮改了什么 | 不会。它们是**依据**，不是产物 |

## 在这里怎么干活

1. **现役技能源在 `mmw/skills-src/`。** 这里的 candidate 不再覆盖现役。
2. **每轮的理由写进 `<上游技能名>/README.md`**，不写进技能正文。
3. **改完跑 `python3 mmw/skill-rebuilds/check-wiring.py`。** 它只判机器能直接判定的四类：相对链接打不开、技能名不存在、启动占位符的角色或组不认识、宿主动作名不认识。
