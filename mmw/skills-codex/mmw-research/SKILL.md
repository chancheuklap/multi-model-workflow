把「去查清楚」派出去，一个题目一个 subagent。

## 两个方向

| 方向 | 查什么 | 出处长什么样 | 纪律文件 |
| --- | --- | --- | --- |
| 内部 | 这个仓库现在怎么实现：模块边界、seam、数据流、调用链、根因 | `文件:行号` | [internal-brief.md](internal-brief.md) |
| 外部 | 仓库之外读得到的：某个库的行为、某个接口的合同、某份规范的语义 | 完整链接，或者命令原文加输出 | [external-brief.md](external-brief.md) |

一个 subagent 只走一个方向，**task 里点名对应纪律文件路径**。两个方向的题目可以在同一次里一起派。

**本技能只管读得到的东西。** 一条事实要真实跑一次才知道——那个服务撑得住多少、几个候选哪个扛得住——那是 `$mmw:mmw-prototype` 的 `EVIDENCE.md`。

**不派的情况**：一个函数、一个已知文件或一条命令能答完的，主 agent 自己读取、检索或运行一次。

## 1. 定题目

一个 subagent 一个题目，每个题目写三样：

| 栏 | 写什么 |
| --- | --- |
| 方向 | 内部还是外部 |
| 角度 | 从哪个方向看 |
| 要回答什么 | 一句话，能判真假。「那个接口支不支持按游标分页」答得上，「那个接口好不好用」答不上 |

题目定几个按这次需要，不设上限。

**内部方向按角度分，不按范围分。** 每个 subagent 都看同一片地方，只有角度那一栏不同。常用的角度：这块功能现在怎么实现、seam 在哪、数据从哪来到哪去、改动会波及谁、测试覆盖到哪。

**外部方向按题目分。** 各查各的，互不相干。

## 2. 亮清单

按这个形状亮一次，**不等回应直接往下派**：

```
| # | 方向 | 角度 | 要回答什么 |
```

## 3. 写 task

一个题目一份。按 **四栏表**（目标 / 读 / 约束 / 验收）填写：

| 栏 | 本角色填写 |
| --- | --- |
| 目标 | 「1. 定题目」里该题的角度 + 要回答什么（一句话） |
| 读 | ① 纪律文件路径（与本 `SKILL.md` 同目录：`internal-brief.md` 或 `external-brief.md`）；② 内部：目标仓库根路径；③ 内部：`mmw domain path` 给出的领域文档路径；④ 已知背景若已落盘则给路径，否则写「无」 |
| 约束 | 只读；不改代码；不提方案。内部：取证不得超出「读」中的仓库根 |
| 验收 | 每条结论带出处（内部 `文件:行号`；外部一手链接或命令+输出） |

## 4. 派发

启动：按名称调用 Codex 原生 subagent `mmw-investigator`，task 传四栏表全文。互不依赖的实例在同一条消息中并行启动，全部完成后再汇总。
题目互不依赖时：同一条消息里并行多个启动调用。

## 5. 过滤

引不出出处的断言丢掉。这一步只看有没有出处，不做判断。

**丢掉的要在你的报告里列出来**：丢了几条、分别是什么。

## 6. 验证

按 `$mmw:mmw-verifying-agent-output`。内部的打开那个 `文件:行号` 看原文对不对得上；外部的点开链接看它是不是一手来源。条目多的时候取证那一半派得出去，判定归你。

**这两类结论自己再查一次**：内部报「没有找到」的；外部出处是二手转述的（纪律文件没被读到时，重派并再次点名 `external-brief.md` 路径，不要自己替它找出处）。

## 7. 综合

跨题目去重，把相关的事实串起来，每条保留出处。**综合不派。**

验证过的事实落到哪里，看这次是谁要它：

| 谁要的 | 落到哪 |
| --- | --- |
| `$mmw:mmw-wayfinder` 的一张 `wayfinder:research` ticket | 那张 ticket 的评论，然后关掉它 |
| 别的技能 | 交回给把你叫起来的那个技能 |
| 用户直接叫你来查 | 写成一份文件，落点用他指定的位置；他没指定就跑 `mmw domain dirs` 按 `adr` 那一行的同级放 |

## 下一步

| 情况 | 下一步 |
| --- | --- |
| 综合完了，是别的技能把你叫起来的 | **移交**：回到那个技能，带上验证过的事实，不是报告原文 |
| 综合完了，是用户直接叫你来查的 | **停**：报查清了什么、报告落在哪、哪些没查清、过滤丢掉了哪几条 |
| 出处点开对不上，或者根本没给出处 | **自己继续**：确认 task 点名了纪律文件与（内部）仓库根，重派这个题目 |
| 内部报了「没有找到」，你自己再查一次却找到了 | **自己继续**：以你查到的为准，这个角度整份降级重验 |
| 报告里提了方案、选了路线 | **自己继续**：那部分不采信，只取事实和出处 |
| 交回「卡住」，理由是找遍了没有一手来源 | **停**：报这个题目查不到一手来源、它查过哪些地方，让用户定是换个问法还是接受不确定 |
| 交回「卡住」，理由是这块代码看不懂 | **停**：报是哪一块、卡在哪里，让用户定换角度还是他自己讲一遍 |
| 查下来发现这条事实读文档答不出来，要真实跑一次才知道 | **移交**：`$mmw:mmw-prototype` 的 `EVIDENCE.md`。把这一轮查到的和排除掉的带过去 |
| 第 1 步题目收不成能答得上的形状 | **停**：说清是要人拍板，还是这个题目得先拆开 |
