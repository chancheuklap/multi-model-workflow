# 起图

**谁读**：主线程，这个任务还没有 `docs/design/<任务名>/wayfind/map.md`。整个任务只读这一次。

起图是一个会话的活，它不解任何决策。

1. **命名目的地**：跟用户谈定一段话，写清走到哪算到。它定死范围，所以先定它。落盘前把这段话念回给用户，等他改或点头。
2. **横扫**：再谈一轮，这次不深挖任何一条线，把目的地之前还没定的事翻一遍。翻不出雾就不需要地图，告诉用户敲 `/mmw-next 查清现状`。
3. **建地图**：目的地与这次的约定填好，已决空着，能精确表述的建成决策文件（编号从 `d-01` 起）列进待解区，说不准的写进迷雾区。
4. **第二遍连挡路关系**——文件得先存在，才引用得了彼此。连完就分出了能解的和被挡的。
5. 查证类先派出去，各自落成一份查证笔记。派与收照 `mmw-wayfind` 那张四类决策表里查证那一行。
6. 停。回 `mmw-wayfind` 按每轮走，一轮拍一块板。
