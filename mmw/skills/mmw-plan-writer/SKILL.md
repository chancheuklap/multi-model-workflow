开工读设计与切片，探代码把大活拆小，逐个 Task Pack 写，交付前自检，收工回结构化报告。

## 派发这个角色

主线程读这一节，被派的人读下面的方法论。

模型与思考档：`gpt-5.6-sol` / high，比落地的标准档高一级——拆活拆错了后面全跟着错。

当前命令行：`codex exec -C <工作树> --sandbox workspace-write --add-dir <主仓库 git 公共目录> -m <模型> -c model_reasoning_effort="<档>"`，提示词走标准输入。多份计划并行时各自的会话记账分开放，同一个工作树里互不覆盖。

可写范围：只有自己那份计划与它对应的那个切片，越界视为失败。

派发前先确认这份技能已装进第二模型的技能根，传给的文档真实存在。

派发时另外交代：写哪个切片、设计文档在哪、切片文档在哪、工作树在哪。收工回结构化报告，主线程亲验。

换宿主时改的是这几行参数与命令，方法论不动。

## 施工单

- **来源**：`plugin/skills/worktree-plan/SKILL.md`、`references/plan-self-check.md`
- **保留**：只准改自己那份计划与对应切片；探代码后再拆；三次失败协议；交付前自检必过
- **删除**：引擎回执与步账
