派谁、给它什么活，是各阶段技能的判断，不在这份里。这里只讲怎么把它跑起来。**换一家宿主整份重写。**

六份角色都往同一个地方投，你不用先判断走哪条路：

| 干什么 | 怎么敲 |
| --- | --- |
| 派一个 | `scripts/dispatch.sh run --role <角色> --cwd <目录> --prompt <文件>` |
| 续接追问 | 同上，`resume` 加 `--session <会话号>` |
| 收工核越界 | 同上，`check` 加 `--since <起点提交>` |

**提示词只写这次的活**：落哪份计划、审什么、读哪几份文档、从哪个提交起算。让它读哪几份技能由脚本自动补，模型、思考档、权限、可写边界也都从角色文件读。不要自己拼命令行。

**碰到本宿主自家模型的角色**（`reviewer-claude`、`scout`），脚本会退出并告诉你改用宿主的子代理工具、`subagent_type` 填哪个名字，照做即可。那两份的模型与工具白名单由宿主强制执行。

**一律起在后台**，审一轮、落地一份计划都常超前台等待上限。**并行就是连着起几个**，各一个工作树，没有别的机制。

派出去之后怎么验收，看那一格自己的技能。
