# 题目清单的格式

**谁读**：主线程。派之前照这个格式亮给用户，别每次自创。

```
投查方向：<内部 / 外部 / 两者>

| # | 角度 | 这一题要回答什么 |
| --- | --- | --- |
| 1 | <角度名> | <问题，问得准到答得上> |
| 2 | ... | ... |
```

亮完跟一句「批、改，还是增删题目？」，等回应再派。
