两个检索工具**怎么用**——什么问题问图、什么问题问符号、哪两类盲区要结合源码看、候选为什么必须回源码验证——写在它们自己的服务器说明里，主 agent 和每一个派出去的工人都读得到，本技能不复述，别处也不要再写一份。

本技能只管它们说明里没有的两件事：**图怎么建起来、怎么保持可用**，以及**工具本身连不上时怎么查**。这两件都只有主 agent 做。

## 1. 为什么图要单独建

原生扫描按语言各扫各的。前端发出的一次请求和后端处理它的那个函数之间，没有任何一条边——两种语言的解析器互相看不见对方。

同一处断裂也让符号查询失效：装饰器注册的处理函数没有静态引用者，动态导入解构出来的符号连不上定义。这两类正是两个工具共同的盲区。

补上它的是建图时单算的那几类跨语言边：

| 边 | 连的是什么 |
| --- | --- |
| 请求到接口 | 前端或另一个服务发出的调用，连到后端处理它的函数 |
| 进程间调用到处理函数 | 渲染进程发出的调用，连到主进程注册的处理函数 |
| 消息生产方到消费方 | 往一个主题写的地方，连到读它的地方 |
| 函数到它注册的路由 | 普通函数，连到装饰器给它挂上的那个接口 |

**这几类边就是检索能不能用的分界。** 少了它们，「这个接口谁在调」「改这个函数影响哪个页面」都答不出来，而且答不出来的样子跟「确实没人调」一模一样。

## 2. 图的三种状态

结构查询自己会在调用前对一次账，但你要看得懂它报的是什么：

| 状态 | 判据 | 处置 |
| --- | --- | --- |
| 缺失 | 图文件不在 | 建一次；不值得等就直接 `Grep`、`Read`，并说明这次没用图 |
| 过期 | 图输入的内容指纹跟建图时不一样 | 同上 |
| 新鲜 | 指纹一致 | 直接查 |

判的是图输入的内容，不是提交号。**Markdown 改动和空提交都不算图过期**——文档不进图，空提交不改任何文件。按提交号判的话，任务 worktree 一建出来就"过期"，主仓库那份现成的图白白复用不了。

## 3. 建一次

```bash
mmw graph build
```

五个阶段，任何一步失败旧图都原样保留：

| 阶段 | 做什么 | 失败意味着 |
| --- | --- | --- |
| 原生抽取 | 按语言扫符号、文件、模块关系，落到暂存目录 | 语言解析器缺了。这时拒绝发布，宁可没有图也不要残的 |
| 跨语言边 | 算第 1 节那几类边 | 某一类算不出来，是配置里对应那一项跟当前代码结构对不上 |
| 合并 | 原生图和跨语言边合成一张 | — |
| 路由桥 | 把普通函数连到它注册的路由 | 出现多个候选，说明代码里有同名处理函数 |
| 校验发布 | 查字段、端点存在、无悬空、无重复、排除路径没混进来，过了才原子替换 | 半成品不会顶掉旧图 |

不要自己拼这条流水线，也不要跳过任何一步单跑其中一段。

## 4. 四条禁止

| 禁止 | 为什么 |
| --- | --- |
| 直接对正式图跑检索工具自带的更新命令 | 它只做原生抽取，跨语言边和路由桥全丢，而文件名和体积看不出区别 |
| 装监听式自动更新或者提交钩子 | 绕过完整流水线，在后台产生说不清来历的图 |
| 把图提交进版本库 | 本机派生物，几十兆，跟着 checkout 走 |
| 图建不出来就停下手上的活 | 它不是阻塞点。记下原因，回文本检索继续做 |

## 5. 工具本身连不上

图是好的，但工具调不动，那是另一件事——这时不该去重建图。

```bash
mmw doctor
```

它真把三个服务器各拉起来握一次手，再拿实际暴露的工具跟裁剪合同逐条比对。只看配置在不在会漏掉一整类故障：配置在、工具名也在列表里，直到模型真去调用才报错，而那时它已经在一次审查的中途了。

| doctor 报的 | 意味着 |
| --- | --- |
| 某个服务器起不来 | 那个 Python 工具包没装。插件替不了你装，命令在它的输出里 |
| 工具集跟合同对不上 | 上游改了默认暴露面。多一个是护栏破了，少一个是能力缺了，两种都要当场处理，不要绕过去用 |
| 用户级配置没装或跟插件定义不一致 | 跑它给出的安装脚本。这一面断了只在换宿主时才会发现 |

**连不上同样不是阻塞点。** 记下原因，回 `Grep`、`Read` 继续做，在报告里写明这次没用检索工具。

## 6. 接入、验证、出错

一个仓库第一次接入，或者查出来的结果不对劲，看 [building.md](building.md)：配置有哪几项、怎么验证建对了、每种失败怎么处置、任务 worktree 怎么复用主仓库那份。

## 下一步

| 情况 | 下一步 |
| --- | --- |
| 图建好了 | **自己继续**：回到把你叫起来的那件事 |
| 图缺失或过期，值得等 | **自己继续**：`mmw graph build`，再查 |
| 图缺失或过期，不值得等 | **自己继续**：直接 `Grep`、`Read`，在报告里写明这次没用图和原因 |
| 建不出来，报了具体的失败阶段 | **自己继续**：按 [building.md](building.md) 的失败处置那一节办 |
| 这个仓库还没接入 | **自己继续**：按 [building.md](building.md) 的接入那一节配一次 |
| 工具调不动，图却是好的 | **自己继续**：`mmw doctor`，按第 5 节那张表办 |
| 图建出来了，但某一类跨语言边是零 | **停**：报这个仓库的检索能力不完整、缺的是哪一类，让用户定是补配置还是先这样用 |
| 结构查询答不出一个你确信存在的关系，图却是新鲜的 | **停**：报这个关系是什么、查过什么，让用户判断是提取算法漏了这种写法还是问法不对 |
