# Write for Where It Is Read

Everything you produce is read or run somewhere other than this conversation: by a person on a web page, by a model starting with an empty context, by a shell that shows one truncated line.

**Pattern:** before you write it, name who will pick it up, what they are trying to do at that moment, and what they can and cannot see from there. Then write for that person, agent or program.

**The test:** a thing that only makes sense from where you sit has not been built yet.

Distinct from the **technical-writing** skill, which shapes the sentences. This decides, before any sentence, whom they are for and what that reader can see.
