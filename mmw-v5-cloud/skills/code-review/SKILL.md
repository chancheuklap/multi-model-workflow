# Code review

When assigned a complete review, perform it in this session, whether you are an independent main reviewer or an implementation worker. After completing the review, return to the task that invoked this skill.

Follow the reference for the review task you were assigned:

| Your task | Read and follow |
| --- | --- |
| Run the complete review, including preparation, the review axes, verification, and the final report | [Main reviewer](references/main-reviewer.md) |
| Review the Standards axis | [Standards reviewer](references/standards-reviewer.md) |
| Review the Spec axis | [Spec reviewer](references/spec-reviewer.md) |
| Review the Tests axis | [Tests reviewer](references/tests-reviewer.md) |
