## Notes

- **release receipt**, definition fact: the entry says "the rendered account of a paused round", but `cmd_receipt` (`release-flow.sh` lines 1326-1340) renders the attempt history of any open release loop, paused or not, and `driving.md` line 23 also reads it on `CORRUPT:`. Drop "paused".
- **fix round**, code against intent: the comment at `release-flow.sh` lines 133-135 says the budget counts every repair round (stage run, classify, fix, gate, full re-run), but only the P2 `derive` commit increments `fix_rounds` (line 331); a P1 fix or a `transient:` re-run never counts, and only the `.round` cap catches them. That is a code question for an engineering ticket, not a vocabulary one; the glossary should describe the code as it is.
- **release loop**: the `ABORTED:` line (`cmd_abort`, "the state of this round is kept") is script output and stays as it is; it will read "round" where the glossary says release loop.
- **MMW** (toolbox line 26) and **retired** (toolbox line 62) say `docs/research/` is frozen. `AGENTS.md` paragraph 2 says only `docs/research/code-landing-refs/` holds read-only snapshots and the rest of `docs/research/` holds research notes a spec may cite. The two entries contradict their `_Home_`. `candidates/toolbox-a.md` notes this under `## Concepts with no entry` but makes no proposal.
- **model-and-level pair**: `editing-models.md` calls the second half "level" (`<level>`, "the reasoning level, saved as the row's `effort`"), while toolbox **`effort`** calls it "the reasoning effort". The name adopted in row 1 inherits that split; `candidates/night-a.md` lists it under `## Concepts with no entry` ("reasoning level").
