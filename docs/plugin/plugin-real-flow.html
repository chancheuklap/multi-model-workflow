Plugin 全貌 · 一张大图

一张图 = plugin 全貌 + 细节。规范性:每个阶段同一套三拍 mmw where → 干 → mmw handoff --conclusion ⟨词⟩;脚本接管统一性:确定步骤全走 mmw 命令(不手搓),节点内「命令」行都是 mmw …。4 开口路径分叉→汇合;外层 phase 引擎 flow.sh + 内层 loop 引擎 loop.sh;审闸/落地是真循环 loop(exit-check NOT-DONE 被 guard-loop 顶回)。节点内 读 / 命令 / 入 / 出 分层,输出取真跑 stdout(slug=realflow;build 真 Codex gpt-5.4、审 gpt-5.5)。

脚本 / 状态机(mmw / flow.sh / loop.sh) Claude 判断 Codex 苦力 审闸 / 判定 实线=推进 · 虚线=返工/掉头/旁路
