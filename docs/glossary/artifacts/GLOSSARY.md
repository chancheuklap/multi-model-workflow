# Artifacts

The HTML files and throwaway code the skills treat as different kinds of artifact. Prototype here is one fidelity mode. It is not the prototype skill, and it is not a wayfinder:prototype decision ticket.

Do not invent a Chinese name for a term in this file, or for any MMW skill. Use the English name.

## Language

**HTML artifact**:
One self-contained HTML file built for a person to read or use. The skill html is the router. A diagram, a plan, a wireframe, or a mockup has its own skill.
_Avoid_: any invented Chinese name.

**wireframe**:
A low-fidelity HTML artifact for what belongs on a screen, how the task moves, and how the layout responds. The skill is html-wireframe.
_Avoid_: any invented Chinese name.

**mockup**:
The static fidelity mode of html-prototype. A polished, mostly static HTML artifact for a visual question: hierarchy, layout, type, color, or product fit.
_Avoid_: html-mockup, and any invented Chinese name.

**Prototype**:
The fidelity mode of html-prototype for a working flow: navigation, input, state change, feedback, recovery, or transition.
_Avoid_: any invented Chinese name.

**diagram**:
A self-contained HTML file whose layout answers one relationship question: sequence, topology, state, hierarchy, or a quantitative structure. The skill is html-diagram.
_Avoid_: any invented Chinese name.

**plan**:
A self-contained HTML file that makes source material easier to inspect: order, ownership, and dependencies. The skill is html-plan. A design plan, the short token sketch written before visual code, is a different note inside design-artifact.
_Avoid_: any invented Chinese name.

**logic demo**:
Throwaway code from the prototype skill: one HTML file that drives a state model through cases that are hard to judge on paper. It is not Prototype, and it is not a wayfinder:prototype decision ticket.
_Avoid_: any invented Chinese name.

**UI prototype**:
Throwaway code from the prototype skill: several structurally different UI variations of one route, switched in the browser. It is not Prototype, and it is not a wayfinder:prototype decision ticket.
_Avoid_: any invented Chinese name.

**wizard**:
An interactive bash script that walks a person through steps only they can perform. The skill is wizard.
_Avoid_: any invented Chinese name.
