# 产物落点由 `mmw artifact path` 回答，技能正文不写路径字面值

MMW 的技能在自己正文里写死产物路径：四个类别根写死 30 处、`<产物目录>` 35 处、`.scratch/` 28 行、`.reviews/` 10 行；同时 `.mmw.json` 把 `scratch` 与 `reviews` 声明成可配置并由 CLI 读取，两边互相矛盾。现在改为：产物落点由 `mmw artifact path <类别> --name <名字段> [--issue <编号>] [--sub <类别内细分>]` 回答，取值数据放 `mmw/cli/artifacts.json`，技能正文只写类别名和这条命令。理由有两条：`AGENTS.md` 的唯一事实来源顺序把 CLI 的机械动作排在技能源之前，而由类别、名字段和范围段拼出目录是机械动作；并且只有一条命令能同时回答固定类别根与工作目录根这两类取值。

## Considered Options

- **九项落点全部写死，工作目录根也固定。** 否决。scratch、reviews、release 和 worktrees 是目标仓库自己的工作目录，会和仓库已有约定撞车，可配置有真实理由。
- **九项落点全部可配置，`.mmw.json` 那五项恢复成真实数据源。** 否决。流程语义要跨仓库一致：一个 agent 在任何装了 MMW 的仓库里都应该在 `docs/specs/` 找到 spec，这一层可配置只会制造分歧。
- **命令只回答工作目录根四项，固定类别根继续在技能正文里照抄字面。** 否决。它把「哪些类别可配置」这条知识复制进每一份技能正文；将来某一项从固定改成可配置，又要改 11 个文件。
- **命令回答全部，技能正文同时保留示例路径当注释。** 否决。注释路径会过期，过期的示例路径和写错的路径对 agent 是一回事。

## Consequences

- `.mmw.json` 的 `specs`、`plans`、`prototypes`、`research`、`evidence` 五项删除。`mmw init` 的迁移已经在做这件事（`mmw/cli/lib/init.sh:61-62`）。另外让 `mmw doctor` 在配置里发现这五项时报一行：`.mmw.json` 是人手改过的文件，静默删除会让改过它的人不知道自己配的东西为什么没生效。
- agent 学会这条命令靠两层，缺一层都会回到猜。第一层是技能正文每个使用点写完整命令行，这是现行做法，有 96 处先例。第二层是 `mmw artifact` 无参输出用法，列出全部类别名和三个参数。
- 三种失败各自不同，都不回退默认值。认不出的类别名：报错并列出全部合法类别名。不落盘的类别（四栏 task、角色报告）：报错并说明这类产物不写文件。不套路径形状的类别（出包状态、出包阶段产物、交付记录、结构图谱、任务 worktree）：报错并指出由 `mmw release`、`mmw graph` 或 `mmw task` 回答。后两类要在产物落点数据里列出来并标明，否则 agent 会以为是自己拼错了类别名，转而去试别的写法。
- 命令默认输出仓库相对路径，`--absolute` 输出绝对路径。产物路径要写进 issue 评论、spec 和交回报告，绝对路径进了这些文本就是错的，而且要换一台机器才会被发现。
- 命令没有副作用，不建目录。读取侧也要问同一条命令，查询带副作用的话，一次「问一下 spec 在哪」就会在仓库里留下一个空目录。
- 类别名用英文小写标识符：`spec`、`plan`、`prototype`、`research`、`adr`、`context`、`out-of-scope`、`scratch`、`review`。`AGENTS.md` 把代码标识符列为保持原形的一类，命令参数属于这一类。无参用法输出打成两列表，左列参数值，右列 leaf 定义的中文术语，两套说法在同一处对上。
- 类别内细分经 `--sub` 交给命令，命令按安全路径段规则逐段校验。字符规则只在一处执行，技能拼出来的段不会没人检查。
- `docs/context/artifact-location.md` 的类别根表在产物落点数据落地时删除，leaf 只留术语层与指向那份数据的权威引用。本次先在 leaf 中加入固定类别根与工作目录根两个术语。
- MMW 源码仓库是使用 MMW 的仓库之一，走同一套落点，不另立一套。`mmw init` 不复制任何 leaf 到目标仓库（`mmw/cli/lib/init.sh:316-325`），所以 leaf 不可能充当技能在目标仓库里查落点的那一处。
- 改动量是 30 处类别根、35 处 `<产物目录>`、28 行 `.scratch/`、10 行 `.reviews/`。实现落在下游。
