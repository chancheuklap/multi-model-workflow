# 产物落点

这个 Context 定义 MMW 产物在仓库中的位置由哪几段构成。它只定义这几段的术语。每一类产物的类别根取值、类别内细分规则和取名方式由产物落点数据承担，见本文末尾的权威来源。

## Language

**路径形状**：
一件产物在仓库中的位置规则，由四段构成：`<类别根>/<名字段>/[<范围段>/]<类别内细分>`。
_Avoid_: 落点合同、目录结构、路径模板

**类别根**：
路径形状的第一段，由产物类别决定。一个类别根只放一类产物。
_Avoid_: 顶层目录、产物根

**固定类别根**：
由 MMW 规定、目标仓库不可改的类别根。
_Avoid_: 默认路径、内置路径

**工作目录根**：
取值由目标仓库自己决定的类别根，取值在 `.mmw.json` 的 `paths`。
_Avoid_: 临时目录、本地目录

**名字段**：
路径形状中标识一次交付的那一段。普通任务取当前任务分支去掉最后一个 `/` 之后的部分。Wayfinder 整项工作取 map 分支同样规则得到的 slug；decision ticket 自己的分支不进入这一段。缺省名字段只在任务 worktree 上的任务分支上成立。
_Avoid_: 任务目录、独立工作名

**工作名**：
已废除的独立标识。现用名字段。不要再把它写成与任务分支不同的第二个值。
_Avoid_: 产物目录、任务 slug、任务分支名

**范围段**：
路径形状中标识 Wayfinder decision ticket 的那一段，值是 `issue-<编号>`。只有 decision ticket 有这一段。
_Avoid_: 子目录、任务段

**类别内细分**：
类别根之下由产物类别自己规定的目录结构。它一律使用目录，不使用文件名前缀。
_Avoid_: 文件名前缀、扁平命名

**当场取名**：
类别内细分由生产它的技能自己取值的取名方式。与它并列的另外三种取名方式是固定文件名、由分配器成批给号和一概念一文件。
_Avoid_: 自由命名、动态命名、临时命名

**产物引用**：
指向一件产物的标识，由类别、名字段、范围段和类别内细分构成，不含路径字面值。它是产物在技能之间传递时的形态；实际路径由 `mmw artifact path` 解析。
把产物引用称为「路径」或「精确路径」是错的。反过来，「路径」和「精确路径」指解析之后的真实文件路径时是正确用词——给 subagent 一份具体文件的位置，那就是精确路径，不是产物引用。
_Avoid_: 产物 ID

**撞名**：
两件产物取到同一个产物引用，因此解析出同一条路径。它只出现在当场取名的类别内细分上。
_Avoid_: 冲突、重名、覆盖、同名

**安全路径段**：
首字符是字母或数字，其余只能是字母、数字、点、下划线、连字符，不含斜杠，一律小写的单个路径段。名字段、范围段和类别内细分的每一段都是安全路径段。
_Avoid_: slug、目录名

**工作名重复**：
两次交付取到同一个名字段。
_Avoid_: 工作名重名、工作名撞名、名字段重名

**不落盘判据**：
能在提示词或标准输入里传完、因而不需要写文件的内容所满足的判据。
_Avoid_: 不落盘类别、无文件产物

类别和落点取值的权威来源：[`mmw/cli/artifacts.json`](../../mmw/cli/artifacts.json)。
