#87 第 1 件的答复（定案 J1）。`15` §5 六行照收，补三条边：closeout-rejected 归入 idle 而 phase 未到 closed/handoff、unknown 重派一次且不升级角色、blocked 由 board.py 关表单后重新 prompt 而不交人。idle 而 phase 未到 closed/handoff = idle/done 且 phase 不是 closed/handoff（定案 H1）。三个计数没有一个存文件。

图 3 · 重新 prompt 时说什么（#87 第 4 件 · 定案 J4）

就是派发词，一个字不多

发给 worker 的

implement #n

  • 词表「派发词」：技能名 + 票号，nothing else；固定的东西一律在技能里
  • worker 停在哪一步，票上已经写着：self-run / VERDICT / REVIEW 各是一条评论，closeout-rejected 是一个 phase
  • implement 收尾段加一句：票上已有这些评论的，从最新那条之后的一步续（merge-note 已记）
  • blocked 关表单之后发的也是它——不问的纪律本来就在技能里

发给 主 agent 的

mmw board: <情况> #n — run board.py --once

  • 只在两种情况：任一上限到了、夜间结束
  • 主 agent 醒来 board.py --once 读一眼，不动手
  • 遵守 15 §3 七条前提：只在它 idle 且 pane 未聚焦时发

#87 第 2、3 件 · 落点 · 先验

第 2 件 · 主 agent 怎么被重新 prompt（定案 J2）

夜里开始时改个名，之后只被叫两次

  • dispatch.sh run 先 herdr agent rename $HERDR_PANE_ID mmw-main
  • board 叫它：herdr agent prompt mmw-main "mmw board: <情况> #n — run board.py --once"，遵守七条前提（它 working 就留到下一轮）
  • worker blocked 不惊动它：board.py 评论 BLOCKED:、关表单、重新 prompt 派发词
  • 上限到了 读一眼，不动
  • 夜间结束 读 NIGHT SUMMARY

第 3 件 · 数字（board.py 顶部常量）

每个数都有一句依据

PARALLEL
2 — 一票两个可见 agent，四个 pane 一屏看得清
COOLDOWN
120 s — 回合间隙常见的 idle
WAKE_BACKOFF
120 → 240 → 480 s
WAKE_LIMIT
3 / 会话 — 与三轮上限同档
REDISPATCH
1 / 票 — 第二次死交 /triage
MAX_HOURS
4 / 票 — 只交回，不杀
SNAPSHOT
60 s — 事件丢了一分钟内补上

落点 · 全在 dispatch 技能

worker 那一侧一字不改

  • scripts/board.py new 三形态：--once / 常驻追加行 / --watch <spec>
  • dispatch.sh run <spec> new 开 board tab、改名、起 watch
  • dispatch.sh <n> <role> 派发时多写 ticket/role token
  • herdr/agent-detection/cursor.toml new 随 install.sh 装、reload、--check
  • verify-ticket.py · hook.py · implement 不改
  • #75 步 4–5 与 AC3 措辞随改；12-decisions.md 记块 J

先验 · 2026-08-31 已实测

  • 通过 cursor / grok 会话的 idle 被 Herdr 认出（cursor 6 s 有推送，grok 8 s）
  • 通过 grok 弹提问框：5 s 报 blocked，agent read 读到整句问题，agent prompt 被拒
  • 通过 手工起的 claude 会话 agent rename 后 prompt 能唤醒（mmw-main 成立）
  • 改设计 按键替答表单会选错项（grok、cursor 都把 Enter 当成选第一项）→ board.py 一律不替答，关表单后重新 prompt 派发词
  • 修好 cursor 的提问表单原本在 Herdr 眼里是 idle → 本地检测规则 ask_question_blocked（~/.config/herdr/agent-detection/cursor.toml），真机验过：blocked、prompt 被拒；board 不写兼容，文件随 install.sh 装、回报上游
  • 通过 关表单后重新 prompt 能续上：grok shift+x、cursor esc，两家都回 idle 并继续
  • 改设计 pane.agent_status_changed 必须带 pane_id → board 订 pane.updated + pane.closed
  • 改设计 另一处 checkout 跑 install.sh 会把软链和 hook 指没 → dispatch.sh run 先 install.sh --check，有缺就拒绝
